# PowerBi_Sales_Dashboard

📊 Sales Dashboard – Power BI
This interactive Power BI dashboard provides a comprehensive overview of sales performance across various dimensions such as time, region, and product category. Designed for business decision-makers and sales analysts, the dashboard helps uncover trends, monitor KPIs, and identify areas for growth.

🔍 Key Features:
KPI Cards: Highlights essential metrics including Total Sales, Total Profit, Total Quantity Sold, and Customer Count.

Time-based Analysis: Sales performance tracked monthly/quarterly with line and column charts to monitor trends over time.

Category & Product Insights: Bar charts and tables showcasing top-performing product categories and individual items by revenue and quantity.

Regional Performance: Sales data segmented by region or country to identify high and low-performing areas.

Interactive Filters/Slicers: Allows users to filter by date range, region, category, and customer segments for dynamic analysis.

Modern Design: Clean layout with consistent color themes, tooltips, and user-friendly navigation.

🛠️ Tools & Technologies:
Power BI Desktop

DAX for calculated measures

Data cleaning and modeling using Power Query
